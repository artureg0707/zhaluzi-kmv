# Жалюзи КМВ — сайт компании

Одностраничный сайт-каталог для компании по изготовлению и монтажу жалюзи на Кавминводах.

**Два адреса сайта (зеркала):**

- **https://artureg0707.github.io/zhaluzi-kmv/** — основной, открывается в России без VPN (GitHub Pages)
- **https://zhaluzi-kmv.vercel.app** — зеркало (Vercel; из России может требовать VPN)

Обновления публикуются сразу на оба адреса (см. ниже).

## Как открыть локально

Просто двойной клик по `index.html` — сайт полностью статический, сервер не нужен.

## Как обновлять сайт (после правок)

В терминале в папке проекта:

```
cd C:\Users\user\.openclaw-autoclaw\agents\auto-designer\workspace\zhaluzi-kmv
vercel --prod --yes
```

Затем синхронизировать зеркало на GitHub Pages (загрузить изменённые файлы в репозиторий artureg0707/zhaluzi-kmv).

## Что где менять

| Что меняете | Где |
|---|---|
| **Телефон и e-mail** (3 места на странице) | начало блока `<script>` в `index.html`: переменные `CONTACT_PHONE`, `CONTACT_PHONE_TEL`, `CONTACT_EMAIL` (текущая почта: artureg0707@gmail.com), `CONTACT_WA`, `CONTACT_TG` |
| **Цены в каталоге** | блок `<section id="catalog">` — тексты `от 1 060 ₽` в карточках |
| **Тарифы калькулятора** | `<select id="calc-type">` — атрибуты `data-rate` (₽/м²) и `data-base` (мин. цена) |
| **Цвета сайта** | блок `:root` в `<style>`: `--accent` (акцент), `--bg` (фон), `--ink` (текст) |
| **Тексты блоков** | соответствующие `<section>` — герои, шаги, FAQ, регионы |
| **Фото** | папка `assets/` — файлы с теми же именами |

## Качество

- Адаптив: десктоп / планшет / телефон (брейкпоинты 1000px и 640px)
- Калькулятор с валидацией ввода и живым пересчётом
- Форма заявки с проверкой имени, телефона и согласия; экран подтверждения
- Мобильное меню-бургер
- Доступность: контраст AA, фокус-контуры, alt-тексты, aria-атрибуты
- `prefers-reduced-motion` поддержан
- SEO: title, description, Open Graph, JSON-LD (LocalBusiness), `lang="ru"`

помечено комментарием `демо-режим` в конце `index.html`.
